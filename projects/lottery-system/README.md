# سامانه قرعه‌کشی

![پیش‌نمایش سامانه قرعه‌کشی](cover.png)

یک سامانه کامل و مدرن برای مدیریت قرعه‌کشی‌ها با قابلیت‌های پیشرفته و امنیت بالا.

**توسعه‌دهنده:** گروه برنامه‌نویسی کا جی اس ام  
**نسخه:** 1.0.0  
**تاریخ:** ۱۴۰۴/۰۳/۲۸ (2025/06/18)

## ویژگی‌ها

- **مدیریت طرح‌های قرعه‌کشی:** ایجاد و مدیریت طرح‌های مختلف
- **مدیریت شرکت‌کنندگان:** ثبت و مدیریت اطلاعات شرکت‌کنندگان
- **ورود اطلاعات اکسل:** آپلود فایل‌های Excel/CSV
- **پرسشنامه:** سیستم پرسشنامه برای جمع‌آوری اطلاعات
- **امنیت بالا:** محافظت از اطلاعات شخصی
- **طراحی ریسپانسیو:** سازگار با تمام دستگاه‌ها
- **زبان فارسی:** رابط کاربری کاملاً فارسی
- **گزارشات:** آمار و گزارشات جامع

## نیازمندی‌ها

- PHP 7.4 یا بالاتر
- MySQL 5.7 یا بالاتر
- Apache/Nginx
- PDO PHP Extension

## راه‌اندازی

### دسترسی کاربران

- **آدرس:** `http://your-domain.com/`
- **نحوه استفاده:** ورود کد ملی و مشاهده کدهای قرعه‌کشی

### دسترسی مدیریت

- **آدرس:** `http://your-domain.com/admin/`
- پس از نصب، رمز عبور ادمین را از صفحه تنظیمات تغییر دهید. رمز پیش‌فرض را در محیط واقعی نگه ندارید.

## راهنمای استفاده

### برای مدیران

#### ۱. ایجاد طرح قرعه‌کشی

1. وارد پنل مدیریت شوید
2. به بخش «مدیریت طرح‌ها» بروید
3. روی «ایجاد طرح جدید» کلیک کنید
4. اطلاعات طرح را وارد کنید
5. طرح را ذخیره کنید

#### ۲. ورود اطلاعات شرکت‌کنندگان

1. به بخش «ورود اطلاعات» بروید
2. طرح مورد نظر را انتخاب کنید
3. فایل Excel/CSV را آپلود کنید
4. سیستم به‌صورت خودکار کدهای قرعه‌کشی تولید می‌کند

#### ۳. مشاهده گزارشات

1. به بخش «گزارشات» بروید
2. آمار و اطلاعات مختلف را مشاهده کنید

### برای کاربران

#### مشاهده کدهای قرعه‌کشی

1. کد ملی خود را وارد کنید
2. پرسشنامه را تکمیل کنید
3. کدهای قرعه‌کشی خود را مشاهده کنید

```
│   ├── schemes.php       # مدیریت طرح‌ها
│   ├── import.php        # ورود اطلاعات
│   └── ...
├── assets/               # فایل‌های استاتیک
│   ├── css/             # استایل‌ها
│   └── images/          # تصاویر
├── config/              # تنظیمات
│   └── database.php     # کانفیگ دیتابیس
├── database/            # فایل‌های دیتابیس
│   └── schema.sql       # ساختار دیتابیس
├── includes/            # فایل‌های مشترک
│   └── functions.php    # توابع
├── uploads/             # فایل‌های آپلود شده
├── index.php            # صفحه اصلی
├── questionnaire.php    # پرسشنامه
└── lottery_results.php  # نتایج قرعه‌کشی
```

## امنیت

- **رمزنگاری رمز عبور:** استفاده از `password_hash()`
- **محافظت از SQL Injection:** استفاده از Prepared Statements
- **CSRF Protection:** توکن‌های امنیتی
- **Sanitization:** پاکسازی ورودی‌ها
- **Session Security:** مدیریت امن نشست‌ها
